# Launch checklist

- Back up Supabase and apply pending migrations.
- Configure environment variables, auth redirects and storage.
- Test Google, payments and email in staging/sandbox.
- Verify each free model/account before enabling candidates.
- Configure approved ad origins and verify Premium exclusions.
- Set support hours, allowances, community URL and plan prices.
- Supply Blogger export to complete historical content recovery.
- Connect an external scheduler if needed.
- Complete staging browser/accessibility verification before publishing.

See docs/upgrade-status.md and reports/verification.md.
